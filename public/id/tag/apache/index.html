    RCE mod_http2 Apache (CVE-2026-119618): Periksa Servermu, Matikan HTTP/2, Patch ke 2.4.71

    Apache 2.4.71 memperbaiki cacat heap corruption kritis di mod_http2 yang bisa berujung pada remote code execution tanpa autentikasi — dan Wiz menemukan 64% cloud environment terekspos. Panduan ini menunjukkan cara memeriksa apakah servermu terdampak, menonaktifkan HTTP/2 sebagai langkah darurat, dan melakukan patch dengan benar.
